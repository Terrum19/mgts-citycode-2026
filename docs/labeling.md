# Разметка кадров: правила

**Где:** http://10.180.132.80:8080 (только через ZeroTier). Регистрация по ссылке-приглашению от Саши.

Два проекта:

| Проект | Что там | Как размечать |
|---|---|---|
| **МГТС dev: проверка авторазметки** (57 кадров) | Рамки уже нарисовала модель | Удали лишнее, подвинь неточное, **дорисуй пропущенное**, проверь статус |
| **МГТС test: разметка с нуля** (108 кадров) | Модели нет | Выдели всё сам |

Test размечаем без подсказок специально: на нём будем честно мерить модели. Если разметка
test будет «подсмотрена» у модели, цифры для защиты окажутся завышенными.

## Что выделять

Выделяй **все** видимые объекты этих типов, а не только тот, что указан в заголовке
(заголовок — куда целилась камера по OpenStreetMap; объекта может и не быть на кадре).

| Метка | Что это | Что НЕ это |
|---|---|---|
| `manhole` (1) | Люк колодца: круглая или прямоугольная крышка в асфальте/плитке/газоне | Ливневая решётка (решётка водостока) — **не размечаем** |
| `pole` (2) | Фонарный столб, опора с кабелями/коробами связи, столб линии | Дорожный знак на отдельной тонкой стойке, светофор, дерево |
| `cabinet` (3) | Металлический шкаф/короб связи или электрики (на земле или на опоре) | Мусорный бак, банкомат, рекламный стенд |
| `other` (4) | Другое оборудование связи, если уверен | — |

- Рамка — **плотно по объекту**, для опоры — от земли до верха (или до края кадра).
- Объект **меньше ~15 пикселей** или почти полностью закрыт (машиной, сугробом) — **не выделяем**.
- Объект обрезан краем кадра, но узнаваем — выделяем видимую часть.

## Состояние (появляется, когда выделена рамка)

- **ok** — исправен.
- **bad** — есть признак неудовлетворительного состояния → выбери вид повреждения
  (наведи на вариант, появится подсказка). Не подходит ни один — `other_damage` + комментарий.
- **unclear** — объект виден, но состояние не разобрать (мелко, тень, ракурс).

Сомневаешься между ok и bad — ставь **unclear**, а не угадывай.

## Кадр целиком (флажки под картинкой)

- `bad_frame` — размыто, засвечено, ничего не разобрать.
- `target_not_visible` — объекта из заголовка на кадре нет. Это нормально, остальное всё равно размечай.

## Быстро

- `1`–`4` — выбрать метку, потом тянуть рамку мышью.
- Выделить рамку кликом → внизу появятся состояние и вид повреждения.
- `Submit` (Ctrl+Enter) — следующий кадр.
- Один кадр размечает один человек: Label Studio сам раздаёт следующий неразмеченный.

## Для координатора

```bash
python3 src/label/export.py        # выгрузка -> data/labels.json
```
Пересоздать/обновить проекты после новых кадров: `split.py` → `make_tasks.py` → rsync кадров на хаб → `ls_setup.py`.
