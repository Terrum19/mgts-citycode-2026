## Быстрые ответы жюри

- **Что означает F1 0,453?** Это F1 повреждения на всех официальных фото для выбранного правила согласия. Истинных автоматических тревог 12, ложных 0, пропущенных для автоматического обнаружения 29. Из этих 29 оператор получил 26. Расчёт: 24 / (24 + 0 + 29). [Покадровые результаты](https://github.com/Terrum19/mgts-citycode-2026/blob/bf606d3363b6da338f2434df50dac7dc0fcd426a/docs/benchmarks/frame_crop_cases.csv)
- **Почему у PM есть F1 0,927?** Это другое правило принятия решения, `8c6845a / det_grounding_qwen235_context`, пересчитанное по сохранённым ответам. Выявлено 38 из 41 повреждения, было 3 ложные тревоги и 3 пропуска. У основного живого прогона PM `d72402c / det_grounding_qwen235` F1 равен 0,900, а сумма полей стоимости API — 0,11860463 USD за партию. [Сводка, таблицы и условия сравнения PM](https://github.com/Terrum19/mgts-citycode-2026/blob/bf606d3363b6da338f2434df50dac7dc0fcd426a/docs/effect/kod_goroda_effect.md)
- **Как получился денежный эффект?** PM задал 12 с на ручной просмотр фото, 25 с на проверку заявки и 650 ₽/ч как допущения. Фактический труд МГТС и сокращение выплат ещё нужно измерить. Число 17,85 с получено как 61 × 12 / 41 и относится к проверке заявок контекстного варианта PM. [Исходные экономические данные PM](https://github.com/Terrum19/mgts-citycode-2026/blob/bf606d3363b6da338f2434df50dac7dc0fcd426a/PMREPLY/economics.csv)
- **Как проверяли рамки?** Основной эталон организаторов описывает один объект на фото. С ним сравнивали итоговый класс снимка. Для оценки точности рамки каждого видимого шкафа понадобится разметка границ объектов. [Реестр снимков](https://github.com/Terrum19/mgts-citycode-2026/blob/bf606d3363b6da338f2434df50dac7dc0fcd426a/docs/benchmarks/event_manifest.csv)
